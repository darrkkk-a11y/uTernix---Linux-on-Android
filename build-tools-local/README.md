# Локальные инструменты сборки на ARM64

Каталог содержит отдельно распакованные пакеты Ubuntu для сборочного окружения. Они не устанавливались в систему. `run-x86-64.sh` запускает отдельную x86-64 Linux-утилиту через QEMU с локальной glibc; при необходимости путь к дополнительным библиотекам задаётся переменной `SDK_LIB_PATH`.

Это средство для **сборки**, а не Android-лаунчер и не среда запуска `.deb`. Успешное выполнение отдельной утилиты не подтверждает работу приложений Electron на телефоне.

Пример, проверенный в текущей среде:

```sh
SDK_LIB_PATH=/usr/lib/android-sdk/build-tools/35.0.1/lib64 \
  sh run-x86-64.sh /usr/lib/android-sdk/build-tools/35.0.1/aapt version
```

Скачанный NDK r29 хранится в локальном SDK, а `ndk-qemu/clang` и `ndk-qemu/ld.lld` — экспериментальные обёртки для него. Проверены отдельная компиляция и отдельная линковка простого объекта для `aarch64-linux-android24`. Компиляция и линковка одним вызовом пока завершается ошибкой запуска дочернего процесса, поэтому полноценная сборка Android-проекта не подтверждена.
