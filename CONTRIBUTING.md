# Contributing to uTernix

uTernix is a Kotlin/Jetpack Compose Android project with vendor Linux and X11 components. Please preserve the native backends when changing UI behavior.

## Before submitting a change

1. Run `python3 tools/design/check_uternix_ui.py`.
2. Run `python3 -m unittest discover -s deb-launcher/tests -v`.
3. Run the Android Gradle unit tests and assemble an APK in a configured Android SDK environment.
4. Verify CUI terminal launch, `.deb` install with/without a Linux guest, native app icon lookup, main navigation, and phone/tablet layouts on device.

## Source and privacy

Never commit APK signing keys, tokens, credentials, downloaded binaries, `local.properties`, build outputs, logs, user data or crash dumps. Keep licensing notices for Tessera, Box64 and Termux:X11 intact. Avoid committing autogenerated design handoff archives or internal reports.

## Versioning and releases

The workflow creates a unique `0.8.0-dev.<run>.r<attempt>` prerelease after a successful build on `main`. Stable releases require separate review, a persistent signing key and hardware smoke tests.
